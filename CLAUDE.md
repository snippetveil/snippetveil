# snippetveil

**This is the public product repository** — plugin source, tests, CI, implementation tickets and
user bug reports. Planning artifacts (the wayfinder map, research, and `docs/spec/v1.md`) live in a
separate **private** repository and are not available from here.

Implementation tickets in this repo are **self-contained**: each one quotes the decision it
implements rather than linking the spec, because the spec is private. Treat the ticket body as
authoritative. If a ticket seems to be missing a decision you need, say so rather than inventing
one — the decision almost certainly exists and the ticket failed to carry it.
